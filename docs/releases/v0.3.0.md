# v0.3.0 リリースノート

## 主な変更点

- `memo serve [--port <port>]` で、ローカルのWebサーバーを起動できるようになりました。`127.0.0.1` だけで待ち受け、既定のポートは `8080` です。`--port 0` を指定すると空いているポートをOSが選び、起動メッセージ `Listening on http://127.0.0.1:<port>` に実際のポートを表示します。
- ブラウザでメモを閲覧できるようになりました。
  - 一覧画面（`/memos`）：ID・タイトル・作成日を保存した順に表示し、タイトルから詳細へ移動できます。
  - 詳細画面（`/memos/{id}`）：タイトル・ID・作成日時・更新日時・本文を表示します。本文は改行や空白をそのまま表示し、長い行は画面の幅で折り返します。
- メモは画面を表示するたびに保存先から読み込みます。サーバーを起動したままCLIで追加・編集したメモも、再起動せずに表示されます。
- `Ctrl+C`（SIGINT）またはSIGTERMで、処理中のリクエストを最大5秒待ってから終了します。
- 保存先を読み込めない場合は「メモを読み込めませんでした」と表示し、エラーの詳細を標準エラーに1行で出力します。サーバーは止まらず、保存先を直せば次の表示から正しく表示されます。
- 全体のヘルプ（`memo help`）に `serve` を追加しました。`memo serve --help` で使い方を確認できます。
- 内部では、Webからメモを読み込むサービス層（`internal/service`）と、Web層（`internal/web`）を追加しました。HTMLテンプレートとCSSはバイナリに同梱しているため、ビルドしたバイナリ1つで動作します。

## 互換性と注意事項

- 保存形式は変わりません。v0.1.0・v0.2.0のJSONは変換せずに利用できます。
- 既存のCLIコマンド（`add`、`edit`、`list`、`show`、`search`、`delete`）の動作は変わりません。全体のヘルプに `serve` の行が加わります。
- Web画面は閲覧専用です。メモの追加・編集・削除・検索はCLIで行ってください。
- 外部のネットワークからは接続できません。認証はありません。
- 本文はMarkdownとして描画せず、書いたままのテキストとして表示します。
- CLIとサーバーの同時利用に対する排他制御は行っていません。CLIの保存は一時ファイルを置き換える方式のため、書きかけのファイルを読み込むことはありません。
- 新しい外部パッケージは追加していません（標準ライブラリのみ）。
